# Automatic-Room-Temperature-Controller-Using-KiwisIoT
An intelligent IoT-based temperature controller using ESP32 and DHT22 to monitor room conditions, automatically switch cooling fans .

## 📌 About the Project

Automatic Room Temperature Controller Using KiwisIoT is an IoT-based smart home automation project designed to monitor and automatically control room temperature.

Using an ESP32 microcontroller and a temperature sensor, the system continuously measures the room temperature. Based on the configured temperature range, it can automatically control a cooling or heating device using a relay module.

The collected temperature data is transmitted through Wi-Fi to the KiwisIoT platform, where users can monitor real-time temperature readings through an online dashboard from anywhere.

This project helps maintain a comfortable indoor environment, reduces unnecessary energy consumption, and demonstrates how IoT technology can support intelligent temperature control and smart home automation.
